When a message is refused

  • Not sent

    The run's inbox is full (at most 16 messages and 65536 bytes per run, withdrawn ones included). Nothing was sent.

  • Not sent

    The message is 9,214 bytes, above the 8192-byte limit; shorten it. Nothing was sent.

  • Not sent

    The run has finished and its inbox is closed. Nothing was sent.

  • Not sent

    The run stopped accepting messages before this one arrived (it ended, or its worker stopped refreshing it). Nothing was sent.

  • Not withdrawn

    Message c0d8e211… was already delivered: the agent has received it, so it cannot be withdrawn. Nothing was changed.

  • Not withdrawn

    Message e4a6f3c2… arrived after the run had ended (late): the agent never saw it, and there is nothing to withdraw.

  • Not accepting

    The run is not accepting messages: it has not started its loop yet, it has finished, or its venue cannot deliver (bind mounts, an exit key and an image with the steer capability).

  • Not read

    Whether the run takes messages could not be read.
