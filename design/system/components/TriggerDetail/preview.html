Before you change it

  • Adding a field the queue does not know (steer, recover, progress, statusComment, awaitInput, mcp, models, maxCostUsd) refuses this trigger's jobs already in line as trigger-skew. 1 waits now: gh-c9e1.
  • Inserting a trigger above row 3 renumbers it, and jobs in line refer to rows by number.
  • If the file does not load, no trigger fires. The page says why, quoting doctor: "The triggers file does not load. pi-dispatch doctor on this host (mini1, 2h ago) says: trigger 5: once needs number."
