The pill timeline groups runs by project. Scroll sideways through retained history, open a run for details, or use Older, Newer and Return to now. The dated preview uses the browser timezone and the offset at that instant. Every retained run remains reachable through bounded history pages, including overlaps and rows outside the picture. Waiting jobs sit after the now line as dashed pills, next to what they wait for, and the Waitlists card counts them by reason and by queue.

Completed runs are quiet grey pills. Only running, parked and failed runs carry colour and labels. An arrow means "after this run" or "needs this slot". A dotted gap means a delay.
