The interactive timeline groups runs by project or host. Drag or scroll horizontally through retained history, zoom, expand the view, and return to live following with Now. Project labels stay fixed. Hover or focus a run for its dated preview, then open details; touch uses an explicit Open run action. Each instant uses its own timezone offset, including the repeated autumn hour. Dense groups expand into individual runs with visual paging, and a list provides another way to navigate. Live updates and Back preserve the inspected time range.

The original Pulse styling stays visible: solid rounded run pills, project tags, segmented controls, quiet dashed time lines, a bottom time ruler and a shaded future area. Short pills keep their outcome symbol without a clipped id; the full name is available in the preview and accessible label. Completed runs are quiet grey. Running, waiting, parked and held-slot facts come from the live snapshot; historical records describe what was recorded. Loading, partial reads and unavailable hosts are stated explicitly. The card uses static sample geometry; the console uses locally bundled vis-timeline and the same design tokens.
