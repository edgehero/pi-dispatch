Words used in these designs

Each word means one thing, on every card.

Glossary

43 words, grouped by where you meet them
TermWhat it meansWhere it shows
Starting work
triggerA rule in triggers.json that says when work starts (cron, label, comment, issue or pull request) and which flow it runs.Triggers, Rules tab
flowThe named steps a job follows, such as fix, triage or review.Triggers, Runs, Spend
jobOne piece of work on the queue, made by a trigger, the CLI or a dispatcher. It becomes a run when its container starts.Overview, Fleet
queueWhere jobs wait in Valkey until a host has a free slot: the shared pi-jobs queue and one per host.Overview (Waitlists), Fleet
in lineA job that has not started, with the one thing it waits for: a slot, another run, a time or check, or retry backoff.Overview
hostA machine running a worker (mini1, mini2, build3), with its slots and budget.Fleet, Host detail
slotRoom for one running job on a host.Overview, Fleet
venueHow a host runs a job's container: local, podman, openshell or openshell-bind.Fleet, Venue detail, Runs
Running
runA job whose container started, from its start to its outcome.Runs, the run page
run recordWhat a run leaves behind: outcome, reason, tokens, cost and times. It holds no issue text.Runs, the run page
re-runStart the same issue, flow and model again. A paid action, previewed first.The run page
forkStart again from an earlier point in a run's session, optionally with another model.Fork a run
steerA message that reaches a running agent at its next turn.The run page
follow upA message that waits until the agent would stop, then reaches it.The run page
Waiting for a person
parkedA run that ended to wait for a person's answer. Nothing waits in a container meanwhile.Parked, Overview
awaiting inputThe record's reason for a parked run, and its outcome word on the Runs page.Runs
approvalA run asks permission for a named action and waits until a person approves or declines.Parked, with the questions
Sandboxes
sandboxA fresh container over a run's workspace, with the job's isolation, no credentials and no agent.The run page, Sandboxes
kept workspaceA run's workspace kept after it ends: 24 hours by default, 7 days when pinned.Sandboxes
prepared sandboxproposed, #771A kept workspace with no run behind it, cloned as one trigger's jobs would see it.Sandboxes
Zero touch and answers
touchproposed, #770A run a person had to act on: an answer, an approval, a re-run, a config fix after a refusal, a steer or a cancel.Zero touch
touch rateproposed, #770Touched runs out of the runs that ended, per project and repository.Zero touch
zero touchproposed, #770A project whose runs needed no person over the window. Merging never counts.Zero touch
answer ruleproposed, #772A hand-written rule that starts a draft job when a run parks. Current word: earlier cards said "answerer".Parked with an answer rule
draft jobproposed, #772The job an answer rule starts: it classifies the question and drafts an answer from cited sources. A person sends it.Parked with an answer rule
standing answerproposed, #772An answer an operator wrote once, which a draft may cite.Parked with an answer rule
Watch and dispatchers
watch ruleA trigger that turns a finding in logs or alerts into a read-only job.Configuration, Watch
findingOne thing a watch rule matched in a stream, with its evidence.Watch
boardA page a watch rule's jobs propose changes to, and a person adopts.Watch board
dispatcherproposedA trigger that reads git changes and infra streams, and may only start listed jobs and propose triggers.Triggers, Dispatchers tab
decision model (Jev)A model that answers choice questions with probabilities and no reasons, used to classify.Watch board, Parked with an answer rule
Money
capA limit on jobs, tokens or dollars per window. A job reserves against it before it calls a model.Spend, Overview
soft holdA mark on the job caps (softHoldPct) from which the worker refuses new starts, before the cap itself.Spend, Overview
envelopeThe outer limit you set once: a dollar total for one window and a floor per project.Budget split
allocationA project's share inside the envelope, moved by a plan of weights. A job over its share is refused before it spends.Budget split
Projects and people
projectA named group of repositories and folders: web, api, billing, ops. Drawn as a tag.Every page
memberA repository or local folder that belongs to a project.Project detail
operatorSigned in with an operator token: may write and act.Sign-in, Access states
viewerSigned in with a viewer token: sees numbers and states, never run text or controls.Run as a viewer
