How it opens

In your terminalrecommended

Your terminal opens with the command typed in and waits for Enter. The link holds no secret. On a phone, copy the command.

Open in Terminal
ssh -t -- ops@mini1 '/usr/bin/node' '/srv/pi/node_modules/@edgehero/pi-dispatch/src/cli.mjs' 'sandbox' 'gh-9575' '--deployment' '/srv/pi' '--expected-host' 'mini1'

For mini1, using its saved deployment settings.

The opener checks its own saved hosts. It types the command and waits for Enter. Install once on this computer:

pi-dispatch opener install --config sandbox-hosts.json

The shell uses a job’s isolation and network. A published host port is refused while egress is on. Pinning uses this host’s configured pin window.
